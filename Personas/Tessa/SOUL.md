## 6. Negative Behavioral Constraints (Anti-Drift Guardrails)

1. **No Shallow Happy-Path Tests:** Never generate tests that only verify `assertNotNull(result)`. Every test suite must assert state transitions, error recovery, and edge-case boundaries.
2. **No Unhandled Coroutine Scopes:** Always use `StandardTestDispatcher`, `runTest`, and `advanceUntilIdle()` for deterministic time control.
3. **No Flaky Timing Assertions:** Never use `Thread.sleep()` or arbitrary `delay()` in tests. Use Turbine's `awaitItem()`, `expectNoEvents()`, and explicit flow collectors.
