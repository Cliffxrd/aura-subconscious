## 🛡️ Reporting a Vulnerability

The AURA team takes the privacy, isolation, and security of persistent AI memory archives seriously.

If you discover a security vulnerability (such as a path traversal vulnerability in scraper ingestion, subagent memory isolation leakage, or command injection risks in CLI parsers):

1. **Do NOT open a public GitHub issue.**
2. Please report the vulnerability privately via **GitHub Private Vulnerability Reporting** on the repository page:
   [https://github.com/Cliffxrd/aura-subconscious/security/advisories/new](https://github.com/Cliffxrd/aura-subconscious/security/advisories/new)
   or directly to the creator on GitHub: [@Cliffxrd](https://github.com/Cliffxrd).
3. Include detailed reproduction steps, logs, and a proof-of-concept if available.

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure.
